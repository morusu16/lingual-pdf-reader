# Polyglot PDF Reader 📖🎙️
多言語対応・学習用PDFリーダー＆音声プレイヤー Webアプリケーション

ブラウザ完結で動作する、語学学習者向けの本格的PDFリーダー＆音声プレイヤーです。
PDFの解析、多言語の文分割、高音質な音声合成読み上げ、読書進捗やメモ・しおりの保存・復元、辞書ポップアップなど、すべての主要機能が外部サーバーや有料APIに頼ることなく、お使いの端末（ブラウザ）ローカルで完結します。

---

## 🚀 主な機能一覧

### 1. 📚 本棚とPDF管理
- **ローカルPDF追加**: ドラッグ＆ドロップまたはファイル選択でPDFを追加（ブラウザ内で高速解析、サーバーへファイルは送信されません）。
- **テキスト直接入力モード**: Webニュースや英文テキストを貼り付けて、自分専用の学習本を作成可能。
- **読書進捗バー**: 読んだパーセンテージ（0〜100%）が本棚カードにリアルタイム反映。
- **安全な削除**: 本を削除すると、関連する進捗、しおり、メモも適切に消去。

### 2. 🎙️ 高品質音声読み上げ（Web Speech API）
- **高音質自然音声の自動優先**: Edge / Chrome の Natural / Online / Neural / Google 音声を自動検知し、クリアで肉声に近い音質で発話。
- **再生 / 一時停止 / 停止**: クリックまたは `Space` キーで操作可能。
- **停止位置の保持**: 音声を停止してもその場で静止し、次回再生時にその位置からスムーズに再開。
- **前後の文スキップ**: `←` / `→` キーやボタンで前後の文にジャンプ。
- **一文リピート**: 苦手な文や発音を納得いくまで何度でも繰り返しリスニング。
- **タップ即時再生**: 本文の任意の文をクリックすると、その文から即座に再生スタート。
- **シークバー**: 400ページ以上の大作でも、シークバーで任意の位置へ一瞬で移動。
- **速度（0.5x〜2.0x）＆ピッチ調整**: 速度バッジをクリックするだけで素早くスピード変更。
- **🔊 音量スライダー**: 0%〜100% で音声を細かく調節可能。
- **🌐 言語強制指定**: 自動判定だけでなく、英語（米/英）、日本語、仏語、独語、西語、中語、韓語などを手動で固定指定可能。

### 3. ✨ リーダー表示・カスタマイズ
- **リアルタイム同期ハイライト**: 読み上げ中の文をハイライトし、画面中央へ自動スクロール。
- **🎨 ハイライト色選択**: 琥珀（Amber）、若草（Green）、空青（Blue）、紫苑（Purple）、桜桃（Pink）から好みの色を選択可能。
- **🔤 フォント切り替え**: 明朝（Serif）、ゴシック（Sans）、等幅（Mono）をワンタップ切り替え。
- **フォントサイズ調整（スマホ対応）**: スマホ画面でもヘッダーの `+` / `-` で簡単に拡大縮小（14px〜32px）。
- **3テーマ対応**: ライト（☀️）⇄ セピア（📜 目に優しい）⇄ ダーク（🌙 夜間用）の3段階切り替え。

### 4. 🧠 学習支援ツール
- **📖 辞書ポップアップ**: 本文の英単語やフレーズをマウスで選択すると、ポップアップで日本語の意味を表示。「メモ帳に追加」ボタンで即座に単語帳へ登録。
- **📌 しおり機能**: 気になった文でコントロールバーの `🔖` ボタンを押すだけでしおりを登録。ヘッダーの「しおり」からいつでも一覧表示＆一発ジャンプ。
- **📑 目次 / ページジャンプ**: ヘッダーの「目次」ボタンから、全ページを検索・一覧して指定ページへ即座に移動。
- **📝 一時メモ（Scratchpad）**: ヘッダーの「メモ」から、本ごとの学習メモをいつでも追加・編集・削除。

### 5. 💾 データ永続化・オフライン対応
- **大容量保存 (IndexedDB)**: PDF本体や抽出済みテキストを端末内に安全に保存。
- **軽量設定保存 (localStorage)**: 読書位置、設定、メモ、しおりを保存し、次回起動時に自動復元。
- **📦 バックアップ（エクスポート / インポート）**: 読書進捗やメモ、しおりを1つのJSONファイルとして書き出し・読み込み可能。
- **📱 PWA & オフライン対応 (Service Worker)**: 一度開けばオフライン環境でも起動・動作可能。

## ⌨️ キーボードショートカット一覧

| キー | 動作 |
|---|---|
| `Space` | 音声の再生 / 一時停止 |
| `←` または `K` | 前の文へ移動 |
| `→` または `J` | 次の文へ移動 |
| 文をクリック | その文から即座に音声再生を開始 |
